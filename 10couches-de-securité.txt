COUCHE 1 — PARE-FEU (Firewall)
Objectif
Filtrer le trafic réseau entrant et bloquer tout accès non autorisé.
Implémentation
Outil utilisé : nftables (successeur moderne d'iptables, natif sur RPi OS moderne)
Fichier : infra/firewall/nftables.conf
nft
table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;
        
        iif "lo" accept
        ct state established,related accept
        
        ip protocol icmp icmp type { echo-request, echo-reply } limit rate 5/second accept
        ip6 nexthdr icmpv6 icmpv6 type { echo-request, echo-reply } limit rate 5/second accept
        
        tcp dport 22 ct state new limit rate over 3/minute drop
        tcp dport 22 accept
        
        tcp dport 443 ct state new limit rate over 20/second drop
        tcp dport 443 accept
        
        log prefix "nftables DROP: " limit rate 5/minute
        counter drop
    }
}
Ports ouverts
Table
Port	Service	Justification
22	SSH	Administration à distance
443	HTTPS	Application FastAPI
Politique de sécurité
DROP par défaut : tout est bloqué sauf ce qui est explicitement autorisé
Rate limiting : 20 connexions/seconde max sur HTTPS, 3/minute sur SSH
IPv4 + IPv6 : support dual-stack via table inet

COUCHE 4 — PROTECTION DoS / RATE LIMITING
Objectif
Empêcher la saturation du serveur par trop de requêtes.
Implémentation multi-niveaux
4.1 Niveau réseau (nftables)
nft
tcp dport 443 ct state new limit rate over 20/second drop
4.2 Niveau application (FastAPI middleware)
Fichier : backend/app/middleware/rate_limit.py
Python
class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, requests_per_minute=60):
        super().__init__(app)
        self.requests_per_minute = requests_per_minute
        self.requests = defaultdict(list)
    
    async def dispatch(self, request: Request, call_next):
        client_ip = request.client.host
        now = time.time()
        
        # Nettoyer anciennes requêtes
        self.requests[client_ip] = [
            t for t in self.requests[client_ip] 
            if now - t < 60
        ]
        
        # Vérifier limite
        if len(self.requests[client_ip]) >= self.requests_per_minute:
            raise HTTPException(status_code=429, detail="Too many requests")
        
        self.requests[client_ip].append(now)
        
        # Headers sécurité
        response = await call_next(request)
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Strict-Transport-Security"] = "max-age=31536000"
        
        return response
4.3 Intégration
Python
app.add_middleware(RateLimitMiddleware, requests_per_minute=60)

class LoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        start = time.time()
        response = await call_next(request)
        duration = time.time() - start
        
        logger.info(
            f'{request.method} {request.url.path} '
            f'{response.status_code} client {request.client.host} '
            f'{duration:.3f}s'
        )
        return response

COUCHE 7 — BLOCAGE AUTOMATIQUE (Ban par compte)
Objectif
Bloquer les comptes après tentatives échouées (indépendamment de l'IP).
Pourquoi pas seulement IP ?
IP dynamique (mobile)
ngrok change l'IP
Plusieurs utilisateurs derrière même IP
Implémentation
Fichier : backend/app/auth.py
Python
# Stockage des tentatives échouées
failed_attempts = defaultdict(list)
MAX_FAILED_ATTEMPTS = 3
LOCKOUT_DURATION_MINUTES = 15

def is_account_locked(mail: str) -> bool:
    now = datetime.utcnow()
    
    # Nettoyer anciennes tentatives
    failed_attempts[mail] = [
        t for t in failed_attempts[mail]
        if now - t < timedelta(minutes=LOCKOUT_DURATION_MINUTES)
    ]
    
    if len(failed_attempts[mail]) >= MAX_FAILED_ATTEMPTS:
        raise HTTPException(
            status_code=403,
            detail="Compte temporairement verrouillé"
        )
    
    return False

def authenticate_admin(db: Session, mail: str, password: str):
    is_account_locked(mail)  # Vérifier verrouillage
    
    admin = db.query(Admin).filter(Admin.mail == mail).first()
    
    if not admin or not verify_password(password, admin.hashed_password):
        record_failed_attempt(mail)
        raise HTTPException(status_code=401, detail="Mot de passe incorrect")
    
    reset_failed_attempts(mail)  # Réinitialiser après succès
    return admin
Comportement
Table
Tentative	Résultat
1-2 échecs	401 + message tentatives restantes
3 échecs	403 + compte verrouillé 15 minutes
Succès	Réinitialisation compteur
COUCHE 8 — CHIFFREMENT DES DONNÉES
Objectif
Protéger les données biométriques sensibles en base de données.
Implémentation
8.1 Type SQLAlchemy personnalisé
Fichier : backend/app/database.py
Python
from cryptography.fernet import Fernet

DB_KEY = os.getenv("DB_ENCRYPTION_KEY")
cipher = Fernet(DB_KEY.encode())

class EncryptedString(TypeDecorator):
    impl = String
    
    def process_bind_param(self, value, dialect):
        if value is None:
            return None
        return cipher.encrypt(value.encode()).decode()
    
    def process_result_value(self, value, dialect):
        if value is None:
            return None
        return cipher.decrypt(value.encode()).decode()
8.2 Colonnes chiffrées
Python
class Employee(Base):

    role = Column(EncryptedString, nullable=False)

COUCHE 9 — MISES À JOUR
Objectif
Maintenir le système à jour contre les vulnérabilités.
Implémentation
9.1 Script de mise à jour
Fichier : infra/scripts/update.sh
bash
#!/bin/bash
LOG_FILE="/var/log/update-fastapi.log"
DATE=$(date '+%Y-%m-%d %H:%M:%S')
MAX_LINES=1000

# Rotation logs
if [ -f "$LOG_FILE" ]; then
    LINE_COUNT=$(wc -l < "$LOG_FILE")
    if [ "$LINE_COUNT" -gt "$MAX_LINES" ]; then
        tail -n "$MAX_LINES" "$LOG_FILE" > /tmp/log-temp
        mv /tmp/log-temp "$LOG_FILE"
    fi
fi

echo "[$DATE] === Mise à jour ===" >> $LOG_FILE

# Python packages
cd /home/fastapi/app
source venv/bin/activate
pip install --upgrade -r requirements-pi4.txt >> $LOG_FILE 2>&1

# Redémarrage
systemctl restart fastapi >> $LOG_FILE 2>&1
systemctl status fastapi --no-pager >> $LOG_FILE 2>&1

echo "[$DATE] === Terminé ===" >> $LOG_FILE
